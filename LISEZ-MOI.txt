MES FINANCES — VERSION INITIALE

PERSONNALISATION : thème Vert élégant par défaut (#173D32 / #B8D9B2). Depuis le bouton ⚙ dans l’en-tête, ouvre Personnalisation pour choisir les couleurs librement ou sélectionner un thème prédéfini. Le choix est conservé sur cet appareil et inclus dans la sauvegarde JSON. Il pourra être synchronisé entre appareils lorsque le service cloud sera configuré.

Fonctions incluses : opérations revenus/dépenses en XOF, EUR, USD ; comptes Espèces, Banque, Mobile Money et Épargne ; soldes initiaux ; budgets mensuels ; objectifs d'épargne ; dettes/créances ; dépenses récurrentes ; rapport simple ; export CSV ouvrable dans Excel ; sauvegarde/restauration JSON ; fonctionnement hors ligne après première visite HTTPS.

IMPORTANT : cette version stocke les données dans le stockage local du navigateur. La synchronisation cloud multi-appareils n'est PAS configurée. Ne saisissez pas d'informations bancaires confidentielles. Exportez régulièrement une sauvegarde JSON. Les taux de change sont indicatifs et manuels.

INSTALLATION SUR IPHONE
1. Décompressez le ZIP.
2. Publiez le contenu du dossier sur un hébergement HTTPS (par exemple GitHub Pages).
3. Ouvrez l'URL publiée dans Safari sur l'iPhone.
4. Touchez Partager > Sur l'écran d'accueil > Ajouter.
5. Ouvrez l'icône Mes Finances.

PUBLICATION GITHUB PAGES (gratuite)
1. Créez un compte sur https://github.com/ (adresse e-mail, mot de passe et nom d'utilisateur).
2. Connectez-vous, cliquez sur le + en haut puis New repository.
3. Nommez le dépôt mes-finances, choisissez Public, puis Create repository.
4. Cliquez Add file > Upload files.
5. Déposez les fichiers contenus dans ce dossier (index.html, manifest.json, icon.svg, sw.js et LISEZ-MOI.txt) dans le dépôt, puis cliquez Commit changes.
6. Allez dans Settings > Pages.
7. Sous Build and deployment, choisissez Deploy from a branch ; Branch = main ; folder = /(root) ; Save.
8. Attendez quelques minutes. GitHub affiche l'adresse du site dans Settings > Pages. Ouvrez-la dans Safari sur l'iPhone et ajoutez-la à l'écran d'accueil.

SYNCHRONISATION CLOUD
Elle nécessite une étape distincte (service d'authentification et base cloud, par exemple Firebase) et des règles de sécurité vérifiées. Ce pack n'inclut pas de synchronisation cloud activée ; ne supposez pas que les données se retrouvent automatiquement sur un autre appareil.
